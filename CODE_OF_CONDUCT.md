# Code of conduct

PyAges contributors and maintainers are expected to keep project spaces
professional, constructive, and welcoming.

Acceptable participation includes respectful technical disagreement, clear
scientific criticism, acknowledgement of uncertainty, and attention to the
needs of people with different backgrounds and levels of experience.

Harassment, personal attacks, discriminatory language, deliberate disclosure
of private information, and sustained disruption are not acceptable. Project
maintainers may edit or remove abusive contributions and may temporarily or
permanently restrict participation when necessary.

Report conduct concerns privately using the contact information on the
maintainer's GitHub profile. Do not use a public issue when a report contains
private or sensitive information.
