# Contributing

The repository-wide contribution policy is maintained in
[CONTRIBUTING.md](https://github.com/dreuzy/pyage/blob/main/CONTRIBUTING.md).
It covers development setup, required checks, scientific changes, data review,
and licensing.

GitHub pull requests are the review boundary. The public can read the source,
open issues, and propose pull requests, but only explicitly authorized
maintainers can modify repository refs or settings.
