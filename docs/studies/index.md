# Site Studies

Site studies preserve observations, configuration, provenance, and scientific
decisions that belong to one field site. They are intentionally separate from
the reusable examples: an example teaches a supported PyAges workflow, whereas
a site study records how that workflow was applied to a particular dataset and
publication question.

Study code is part of the source repository and is not installed in the PyAges
wheel. Clone or download the repository before running commands whose paths
start with `sites/`.
